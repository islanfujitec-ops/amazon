# 📢 MODO PROMOCIONAR - GUIA COMPLETO

## 🎯 O QUE FAZ

A aba **📢 Promocionar** automatiza o envio dos **melhores preços** para seu grupo/número WhatsApp:

```
✅ Detecta automaticamente os melhores preços
✅ Dos produtos das keywords que você configurou  
✅ Envia mensagem formatada com FOTO + NOME + PREÇO
✅ Inclui link de afiliado (seu tag: tainadadecio-20)
✅ Intervalo configurável: 5 minutos até 12 horas
✅ Automático e contínuo
```

---

## 🚀 COMO USAR

### **Passo 1: Entrar na aba Promocionar**

1. Abra o dashboard: `http://localhost:3000`
2. Clique na aba: **📢 Promocionar**

### **Passo 2: Configurar WhatsApp**

Na aba, preencha:

```
📱 Número WhatsApp:
   - Formato: 55XXXXXXXXXX (código país + número)
   - Exemplo: 5585987654321 (Brasil)
   - Pode ser grupo ou número individual
```

### **Passo 3: Configurar Frequência**

```
📊 Frequência de envio:
   ☑️ A cada 1 hora (padrão)
   ☑️ A cada 6 horas
   ☑️ A cada 12 horas
   (Em breve: 5 minutos até 12 horas configurável)
```

### **Passo 4: Ativar Automático**

```
☑️ Ativar envio automático
   → Quando marcado, envia automaticamente nos intervalos
   → Quando desmarcado, envia apenas manual
```

### **Passo 5: Salvar**

```
Clique: 💾 Salvar Configurações
```

## 🔧 TROUBLESHOOTING

### **"Nenhum produto monitorado"**
→ Configure marcas e keywords em **🏷️ Marcas & Keywords**

### **"Número WhatsApp inválido"**
→ Use formato: 55XXXXXXXXXX (código + número)

### **Não está enviando automático**
→ Servidor precisa estar rodando 24/7
→ Use Vercel, Heroku ou VPS

### **Link não funciona**
→ Copie e cole a mensagem manualmente
→ WhatsApp Web precisa estar aberto

## 📱 SETUP WHATSAPP GRUPO

### **Obter link do grupo WhatsApp:**

1. Abra seu **Grupo no WhatsApp**
2. Toque no **nome do grupo** (topo)
3. Procure por **"Link de convite"**
4. Copie o código do convite:
   ```
   https://chat.whatsapp.com/XXXXXXXXXXXXXXXXX
   ```

5. O **número/ID** geralmente é:
   ```
   Mensagens em grupo: nome@g.us
   Chats individuais: 55XXXXXXXXXX@s.whatsapp.net
   ```

### **Ou use direto o número:**

```
Formato: 55 + DDD + Número
Exemplo: 5585987654321
```
