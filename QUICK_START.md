## ⏱️ PASSO 1: Evolution API (5 MINUTOS)

### **1.1 Crie conta gratuita**
```
Abra: https://dashboard.evolution-api.com/
Clique: "Criar conta"
Email: seu@email.com
Senha: qualquer senha
Confirme
```

### **1.2 Dentro do dashboard**
```
1. Esquerda → "Instâncias"
2. Botão azul "+ Nova instância"
3. Nome: "tabuleiro360"
4. Clique criar
```

### **1.3 Configure WhatsApp**
```
Dentro da instância:
1. Esquerda → "QR Code"
2. Abra WhatsApp no seu telefone
3. Câmera → Escaneie o QR Code
4. Confirme no telefone
```

### **1.4 Copie suas credenciais**
```
Esquerda → "Conectar API"
Você verá:
  • API URL: https://xxx.evolution-api.com
  • API KEY: sua_chave_super_secreta

COPIE AMBOS ⭐
```

## ☁️ PASSO 3: Vercel (5 MINUTOS)

### **3.1 Conecte Vercel**
```
Abra: https://vercel.com
Clique: "New Project"
Selecione: seu repositório "tabuleiro360"
Clique: "Import"
```

### **3.2 Configure Variáveis**
Na página de configuração, procure "Environment Variables" e adicione:

```
AMAZON_CREDENTIAL_ID
Valor: (copie de Associados Amazon)

AMAZON_CREDENTIAL_SECRET
Valor: (copie de Associados Amazon)

AMAZON_PARTNER_TAG
Valor: seu-tag-aqui-20

AMAZON_MARKETPLACE
Valor: BR

EVOLUTION_API_URL
Valor: https://xxx.evolution-api.com  (copie de Evolution API)

EVOLUTION_API_KEY
Valor: sua_chave_super_secreta  (copie de Evolution API)

WHATSAPP_TARGETS
Valor: 5585XXXXXXXXXX (seu número)

PROMO_FREQUENCY
Valor: 60

PROMO_AUTOMATIC
Valor: true
```

### **3.3 Deploy**
```
Clique: "Deploy"
Aguarde 2-3 minutos
Pronto! ✅
```

## 📊 CUSTOMIZE SEUS NÚMEROS

### **Mudar frequência de envio:**

**Em Vercel:**
```

```

### **Adicionar mais números/grupos:**

```

```

