📡 API ENDPOINTS:
═════════════════════════════════════════════════════════════════════════════════

GET  http://localhost:3000/          ← Interface web
GET  http://localhost:3000/api/config        ← Carregar config
POST http://localhost:3000/api/config        ← Salvar config
GET  http://localhost:3000/api/monitor       ← Executar busca
GET  http://localhost:3000/api/history       ← Carregar histórico
GET  http://localhost:3000/api/clear-history ← Limpar histórico


🔄 COMO FUNCIONA:
═════════════════════════════════════════════════════════════════════════════════

1. INICIAR:
   └─ Clique em INICIAR.ps1

2. SERVIDOR INICIA:
   └─ Node.js carrega server.js
   └─ Express abre porta 3000
   └─ Navegador abre http://localhost:3000

3. INTERFACE CARREGA:
   └─ HTML + CSS + JavaScript
   └─ Carrega suas configurações de config.json
   └─ Mostra 4 abas

4. VOCÊ CONFIGURA:
   └─ Email e senha Amazon
   └─ Número WhatsApp
   └─ Frequência
   └─ Marcas e keywords
   └─ Tudo salvo em config.json

5. EXECUTA BUSCA:
   └─ Clique "Buscar Agora"
   └─ Server faz requisição para Amazon
   └─ Cheerio faz parsing do HTML
   └─ Mostra resultados em tempo real

6. AUTOMÁTICO:
   └─ node-cron agenda a tarefa
   └─ A cada X tempo, executa busca
   └─ Salva histórico
   └─ Envia WhatsApp (se configurado)
